File Navigator

Step through the files of a folder when viewing local files in Chrome.

File access is off. Turn on Allow access to file URLs on the extension's details page, otherwise nothing happens on local files.

Order

Names sort naturally, so photo2 comes before photo10.

Which files

Kinds are images, videos, audio, PDFs, text files and HTML files. "All viewable files" mixes them, but still skips files Chrome would download.

On screen

Shows e.g. "12 / 48 · photo.jpg" at the bottom of the page.

Shows the file name, ‹ › buttons with its position in the folder, and a button back to the folder (or press Backspace in images and text files).

Slideshow

Press S or Space on an image, or use the ▶ button in the header bar. On a video, S or ▶ plays all videos in the folder, each to the end.

Music

Plays the whole folder, with shuffle, repeat, cover art and the track names from MP3 tags. Media keys work too. When off, audio opens in Chrome's own player.

Folder view

Where the toolbar icon and Alt+Shift+E open the folder view, e.g. ~/Music or /home/me/Photos. Leave it empty for the last folder you browsed. Opens now: …

The List / Grid switch at the top of a folder overrides this for that folder.

Folders first, file-type icons, a clickable path and a filter box. Uses the sort order and hidden-file setting above. Keys: ↑ ↓ select, Enter or → open, Ctrl Enter open in a new tab, ← or Backspace parent folder, type letters to jump, / filter, Esc clear.

Markdown and CSV

A switch at the top right of each file flips between the two.

Keyboard

← →Previous / next file in images and text files
Home EndFirst / last file in images
BackspaceBack to the folder in images and text files
FFullscreen in images and videos; it stays on while stepping
S or SpaceStart / stop a slideshow in images (Space only in images)
SPlay all videos in the folder, one after the other
+ − 0 1Zoom in / out, fit to window, actual size in images
EscStop the slideshow and leave fullscreen

The shortcuts work everywhere, including PDFs, videos and HTML files. Chrome only lets you change them on its own shortcuts page.
