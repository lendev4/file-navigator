# Privacy

File Navigator does not collect, store or send any personal data.

- **Your files** are only read in your browser, to show them: folder listings,
  file contents for the viewers, and images you copy. Nothing leaves your
  computer.
- **Settings** you change, and small things the extension remembers (the last
  folder you browsed, the List / Grid choice per folder, the music player's
  volume), are saved in Chrome's extension storage. If Chrome sync is on,
  Chrome syncs the settings between your devices like any extension's; the
  extension itself never sends them anywhere.
- **No network requests of its own.** The extension doesn't contact any
  server and contains no analytics or tracking. A Markdown file you open may
  itself contain images from the web; those load like on any web page.
